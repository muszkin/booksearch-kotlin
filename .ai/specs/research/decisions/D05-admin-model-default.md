# D05 — Administrator configures the default model
- Date, owner: 2026-09-12, muszkin
- Context and the options weighed: The model could be fixed in code, selected for each task, or configured by an administrator.
- Decision and why: An administrator sets a default OpenRouter model; task-level selection is not required for the first version.
- Consequences, and what would make us revisit it: The model configuration must be validated against the provider's live capabilities.
