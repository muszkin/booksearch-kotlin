# D15 — User confirms the contextual search result
- Date, owner: 2026-09-12, muszkin
- Context and the options weighed: Search can automatically download a matching title or require a user to select from its results.
- Decision and why: The user manually selects a search result before the system validates that it is an EPUB in Polish by the same author.
- Consequences, and what would make us revisit it: No search result is automatically downloaded as contextual material.
- Status: active
