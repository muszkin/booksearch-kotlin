# D13 — Sample and disclose one to five contextual chapters once
- Date, owner: 2026-09-12, muszkin
- Context and the options weighed: Contextual chapters can be selected manually, sampled afresh on each run, or sampled once and retained.
- Decision and why: The user selects a count from one to five; the system samples chapters once when the contextual book is added and shows the selection before use.
- Consequences, and what would make us revisit it: The selected chapter identifiers must be persisted so later translations are reproducible; a default count is still open.
- Status: active
