# D12 — Acquire a contextual Polish EPUB through the existing search flow
- Date, owner: 2026-09-12, muszkin
- Context and the options weighed: A contextual reference can be restricted to existing library entries or fetched by its title.
- Decision and why: The user may use the existing search and download flow to acquire a contextual book. It must be an EPUB in Polish by the same author, is added to the normal library, and is not deliverable to Kindle or PocketBook.
- Consequences, and what would make us revisit it: The library and delivery surfaces need a durable contextual-reference flag and ownership enforcement. Non-EPUB, non-Polish, and different-author results are rejected for this role.
- Status: superseded by D18
